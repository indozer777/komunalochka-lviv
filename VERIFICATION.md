Перевірено Premium (неправильний і правильний ключ), обчислення, помилкові показники, власні тарифи, CORS, застосування пропозицій лише за кнопкою, місячні знімки, історію та графік, два помешкання, HTML-екранування назви, JSON-експорт/імпорт, друк, тему після перезавантаження та відмову сховища.

- Реальна перевірка офіційних джерел у Chrome показала **CORS/мережеву відмову всіх трьох постачальників**. Інтерфейс відобразив причину, ставки не змінилися, ручний режим доступний. Успішні відповіді адаптерів перевірено контрольованими відповідями E2E, а не заявлено як успішний live-fetch.
- Джерела тарифів прочитані під час розробки; посилання та періоди наведені в README. Необхідно звіряти застосовність ставок для свого договору.
- GitHub CLI підготовлено локально в робочому каталозі, контрольну суму звірено з офіційним релізом. Наявний вхід у GitHub підтверджено. Фактичний URL репозиторію та результат публікації наведені у повідомленні з результатом роботи.
- Локальний Git-репозиторій підготовлено з початковим комітом `Initial commit: Lviv utility calculator`. Оскільки автор Git користувача не налаштований, коміт має технічного автора `Codex <codex@localhost>` без зміни глобальних налаштувань Git. У ZIP містяться вихідні файли без `.git`.
- Підготовлено приватний проєкт Sites і статичну збірку. Кінцевий статус та URL розгортання підтверджуються окремим результатом сервісу й наведені у чаті; реєстрація проєкту сама по собі не вважається публікацією.

## Оновлення: передача газових показників

- Погоджений сценарій: підготовка та копіювання даних у «КомуналОчці», фактичне подання користувачем в офіційній формі. Прямих POST-запитів із показниками не реалізовано.
- `tests/transfer.cjs` — успішно в Google Chrome. Використано лише синтетичні рахунки та контрольовані сторінки; **реальних показників постачальникам не подавали**.
- Перевірено рахунки двох сервісів, телефон, перші літери прізвища, цілі накопичені показники, дати, повторну підготовку, незмінність знімків, копіювання та його fallback, перехід на сталий офіційний URL, власне підтвердження лише після явної відмітки, збереження після перезавантаження й ізоляцію двох помешкань.
- Перехоплені зовнішні запити — лише GET без тіла та без реквізитів у URL. Жоден перехід не змінює статус на підтвердження провайдера.
- Перевірено ширини 390, 768 і 1440 px, без горизонтального переповнення; знімки форми переглянуто. Відновлення фокусу при заміні вмісту модального діалогу виправлено.
- П’ять нових тестів ядра охоплюють валідацію підготовки, міграцію старих v1-даних і відкидання неправдивих статусів або порушеного порядку подій.
- Основний браузерний набір `tests/browser.cjs` повторно пройшов після змін: Premium, калькулятор, тарифи, JSON, PDF, історія, теми та стійкість localStorage працюють.
