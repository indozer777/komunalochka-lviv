# Стан перевірки

Підготовлено 19.10.2026.

- `node --check app.js` — успішно.
- `node --check tests/browser.cjs` — успішно (перевірка синтаксису, не виконання E2E).
- `node --test tests/core.test.cjs` — 12 із 12 тестів успішні.
- `node scripts/build.mjs` — успішно, чотири статичні вебфайли скопійовані в `dist/`.
- Статична перевірка HTML — унікальні ID, усі локальні ресурси існують; JSON-маніфести коректні.
- Формули охоплюють п’ять послуг, одну/дві зони, копійчане округлення, дробову річну потужність, нульові обсяги, виключені послуги та числові ліміти.
- Перевірено ключі, імпорт зі зламаною схемою/історією, повторний розрахунок імпортованих сум, HTML-екранування та розрізнення побутового й оптового тарифів.
- **Браузерні E2E пройшли в Google Chrome** після надання доступу. Перевірено Premium (неправильний і правильний ключ), обчислення, помилкові показники, власні тарифи, CORS, застосування пропозицій лише за кнопкою, місячні знімки, історію та графік, два помешкання, HTML-екранування назви, JSON-експорт/імпорт, друк, тему після перезавантаження та відмову сховища.
- Перевірено ширини **390, 768 і 1440 px**: горизонтального переповнення немає. Переглянуто знімки головної, історії та темної теми. Виправлено українське відображення місяця незалежно від мови Chrome та контраст сум у темній темі. Знімки QA зберігаються окремо від репозиторію.
- Реальна перевірка офіційних джерел у Chrome показала **CORS/мережеву відмову всіх трьох постачальників**. Інтерфейс відобразив причину, ставки не змінилися, ручний режим доступний. Успішні відповіді адаптерів перевірено контрольованими відповідями E2E, а не заявлено як успішний live-fetch.
- Джерела тарифів прочитані під час розробки; посилання та періоди наведені в README. Необхідно звіряти застосовність ставок для свого договору.
- GitHub CLI підготовлено локально в робочому каталозі, контрольну суму звірено з офіційним релізом. Наявний вхід у GitHub підтверджено. Фактичний URL репозиторію та результат публікації наведені у повідомленні з результатом роботи.
- Локальний Git-репозиторій підготовлено з початковим комітом `Initial commit: Lviv utility calculator`. Оскільки автор Git користувача не налаштований, коміт має технічного автора `Codex <codex@localhost>` без зміни глобальних налаштувань Git. У ZIP містяться вихідні файли без `.git`.
- Підготовлено приватний проєкт Sites і статичну збірку. Кінцевий статус та URL розгортання підтверджуються окремим результатом сервісу й наведені у чаті; реєстрація проєкту сама по собі не вважається публікацією.
