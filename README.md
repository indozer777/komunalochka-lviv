# КомуналОчка · Львів

Український вебзастосунок для особистого обліку п’яти комунальних послуг у Львові. Сучасний адаптивний інтерфейс, автоматичний підсумок, збереження чернеток за місяцями та окремі тарифи для кожного помешкання.

## Швидкий запуск

Для самого застосунку **не потрібні npm, сервер, реєстрація або API-ключі**. Відкрийте `index.html` у сучасному Chrome, Edge, Firefox або Safari. Усі основні функції працюють із локальних файлів; вебшрифт замінюється системним, якщо інтернет недоступний. Поведінка localStorage на адресах `file://` залежить від браузера, тому для стабільної адреси рекомендований HTTP-сервер:

```sh
cd komunalochka-lviv
python3 -m http.server 4173 --bind 127.0.0.1
```

Відкрийте [http://127.0.0.1:4173](http://127.0.0.1:4173). Зупинка — `Ctrl+C`. Після перенесення сайту на інший домен дані потрібно перенести через резервну копію: localStorage прив’язаний до адреси сайту.

1. Оберіть місяць.
2. У розділі **Тарифи** звірте базові ставки. Увімкніть **Власні тарифи**, щоб редагувати їх. Для сміття введіть ставку вашого перевізника.
3. Внесіть попередні й поточні показники, річну потужність доставки газу та кількість мешканців. Вимкніть послуги, яких немає у вашому помешканні.
4. Чернетка зберігається після кожної зміни. **Зберегти розрахунок** створює запис місяця з копією показників і тарифів.
5. Кнопка **Спробувати на прикладі** після підтвердження заповнює демонстраційні дані. Це явна заміна поточної чернетки; ставка сміття 45 грн у прикладі умовна.

## Стек та архітектура

Vanilla HTML5 + сучасний CSS3 + сучасний JavaScript. Свідомо без фреймворку, Tailwind CDN та залежності від графічних бібліотек: застосунок запускається без збірки, не завантажує сторонній JavaScript і має менше точок відмови. Manrope завантажується через Google Fonts; є системний запасний шрифт.

```text
index.html              Семантичний інтерфейс, навігація, модальні діалоги
styles.css              Адаптивність, світла/темна теми, анімації, друк
app.js                  Стан, формули, перевірка даних, DOM, тарифи, Premium
favicon.svg             Локальна піктограма
README.md               Ця документація
.gitignore              Секрети, залежності, збірки, службові файли
package.json            Необов’язкові команди перевірки й збірки
scripts/build.mjs       Копіювання статичних файлів у dist/
tests/core.test.cjs      Автономні тести розрахунків та валідації
tests/browser.cjs       Браузерні E2E-тести основних функцій
tests/transfer.cjs      E2E передачі показників через офіційні форми
.openai/hosting.json     Ідентифікатор приватного прев’ю Sites; не є секретом
```

`app.js` ізольований у функції. Чисте ядро доступне як `window.KomunalCore` у браузері та `module.exports` у Node.js. Тому формули перевіряються без DOM і без інтернету. Навігація використовує hash-адреси: `#dashboard`, `#tariffs`, `#history`, `#profiles`, `#transfer`.

Схема сховища `komunalochka.lviv.v1` містить версію, обраний місяць, активне помешкання, його чернетки за місяцями, власні тарифи, завершену історію, тему та демонстраційний ключ. Історія зберігає знімок тарифів: подальша зміна ставки не змінює стару квитанцію. Повторне збереження місяця потребує підтвердження, дублікати не створюються. Відкриття запису історії відновлює його показники та ставки у калькуляторі.

## Формули

| Послуга | Розрахунок |
| --- | --- |
| Газ | `(поточний − попередній), м³ × тариф` |
| Вода та водовідведення | `(поточний − попередній), м³ × сумарний тариф` |
| Електроенергія, одна зона | `(поточний − попередній), кВт·год × денний/базовий тариф` |
| Електроенергія, дві зони | `денне споживання × денний тариф + нічне × нічний тариф` |
| Доставка газу | `річна замовлена потужність, м³ ÷ 12 × тариф за м³ місячної потужності` |
| Сміття | `тариф за особу на місяць × зареєстровані мешканці` |

Для доставки вводиться **річна замовлена потужність із рахунку оператора**, а не поточне споживання газу. Якщо у рахунку наведена лише місячна потужність, помножте її на 12. Мінімальну замовлену потужність калькулятор самостійно не визначає.

Усі тарифи вводяться **з ПДВ**. Кожна послуга округлюється до копійок, загальна сума — сума цих значень. Проміжна місячна потужність не округлюється. Нульові обсяги допустимі. Порожні значення не перетворюються на нулі; частковий підсумок позначається. Від’ємні числа, зворотні показники, дробові мешканці, експоненти, некоректні символи та суми понад ліміт відхиляються. Підтримуються кома й крапка та до 6 десяткових знаків; вводьте числа без розділювачів тисяч.

Спеціальні пільгові схеми електроопалення, три зони, опалення, утримання будинку, абонплата, борги, субсидії та пільги не входять у розрахунок. Квитанція є особистим розрахунком, не підтвердженням оплати.

## Передача газових показників через офіційну форму

Функція доступна **без Premium** у меню **Передати показники** або за кнопкою в підсумку калькулятора. Наразі вона підтримує газ; вода й електроенергія розраховуються як раніше.

1. Оберіть **Газмережі · Львів** або **Нафтогаз України**. Для «Газмережі» потрібен 10-значний рахунок із платіжки за доставку; для Нафтогазу — окремий 9-значний рахунок за газ. Це не заводський номер лічильника.
2. Внесіть реквізити та дату зняття показника. Для форми Нафтогазу потрібні перші три літери прізвища власника й український номер телефона. Рахунки двох сервісів зберігаються окремо для кожного помешкання.
3. Попередній і поточний показники беруться з калькулятора обраного місяця; їх можна змінити. Для подання потрібні **накопичені цілі м³**, а не споживання за місяць. Дробові значення не обрізаються мовчки — форма просить виправити їх. Попередній показник необов’язковий, якщо він уже є в офіційному кабінеті.
4. Натисніть **Підготувати передачу**. Перевірте незмінний знімок даних, скопіюйте потрібні значення окремо або все разом. Якщо буфер недоступний, з’явиться поле для ручного копіювання.
5. Відкрийте [кабінет «Газмережі»](https://my.grmu.com.ua/login) або [форму Нафтогазу](https://gas.ua/uk/indicators), перенесіть дані, за потреби увійдіть і **завершіть відправлення на офіційному сайті**. Автозаповнення чужої сторінки, обхід входу чи CAPTCHA не виконуються. Доступність конкретного оператора й періоду приймання визначає сервіс.
6. Після того як сервіс підтвердив прийняття, поверніться та натисніть **Я отримав підтвердження на сайті**. Поставте явну відмітку; за бажанням збережіть номер або примітку підтвердження.

Журнал розрізняє **Підготовлено**, **Перехід до форми** та **Позначено вами як передане**. Жоден із цих статусів не видається за автоматичне підтвердження провайдера. Натискання посилання саме по собі не надсилає показники; дані не додаються до URL чи HTTP-запиту переходу. Паролі та SMS-коди вводяться лише в офіційному сервісі.

Підготовка однакових даних повторно відкриває той самий запис. Зміна показника створює інший знімок, не переписуючи попередні. Кожне помешкання має власний журнал до 200 записів. Запис видаляється після підтвердження. Очищення реквізитів форми не видаляє знімки журналу — їх можна видалити окремо.

Схема localStorage залишається `v1`; старі дані та резервні копії без розділу `gasTransfer` автоматично отримують порожні налаштування. Розрахунки й історія не скидаються. Нові записи перевіряються при відновленні копії: значення, статуси, дати, порядок подій та унікальні ID. Прямий API надсилання не підключений; погоджений сценарій використовує офіційні форми.

### Онлайн-перевірка та fallback

При першому відкритті й за кнопкою **Перевірити онлайн** застосунок паралельно виконує запити `fetch` до офіційних сторінок Нафтогазу, Львівводоканалу та Львівобленерго. Кожен запит має тайм-аут 6,5 секунди. Сторінки розбираються як текст; їхні скрипти не виконуються. Консервативні адаптери шукають підписані побутові тарифи й відкидають неоднозначні відповіді та оптові ставки.

Багато постачальників забороняють CORS або показують тарифи лише після виконання JavaScript. У такому разі статус прямо повідомляє про недоступність, ставки залишаються незмінними, а **Власні тарифи** завжди доступні без Premium. Не використовується сторонній CORS-проксі.

Знайдені значення є **пропозиціями**, а не автоматичним підтвердженням чинності. Перевірте дату дії в джерелі, натисніть **Застосувати знайдені ставки**; це ввімкне власний режим і збереже ставки в поточному помешканні. Нічна ставка не виводиться автоматично з денної. Неправильне введення в редакторі показує помилку й не перезаписує останню коректну збережену ставку.

Для надійного промислового оновлення потрібен окремий контрольований серверний адаптер із перевіркою формату, періоду та категорії споживача. Поточна архітектура залишається цілком клієнтською.

## Premium

Без активації доступні всі п’ять розрахунків, ручні тарифи, збереження чернеток і місячних записів, підготовка передачі газових показників та її журнал. За замовчуванням Premium-функції заблоковані:

- **Історія й графіки**: доступний SVG-графік останніх 12 фактично збережених місяців. Перемикання між гривнями, кВт·год і м³. Є таблиця, відновлення показників, PDF і видалення запису після підтвердження. Пропущені місяці не підміняються нулями.
- **До 5 помешкань**: назва, адреса у Львові, окремі чернетки, тарифи й історія. Видалення потребує підтвердження.
- **Квитанція у PDF**: охайний шаблон A4 з формулами, тарифами та сумами через системний друк. У діалозі браузера виберіть **Зберегти як PDF**. Це не пряме завантаження готового PDF-бінарника.
- **Персональні поради**: прозорі локальні сценарії економії води та електроенергії, порівняння із збереженим місяцем. Зовнішнього ШІ та гарантованої економії немає.
- **Темна тема**: перемикається кнопкою місяця у верхній панелі та зберігається.
- **JSON-копії**: експорт і відновлення після перевірки схеми. Поточні дані замінюються лише після підтвердження. Імпорт перераховує історичні підсумки замість довіри до довільного поля `total`.

### Чотири дійсні ключі активації

```text
LVIV-2026-HOME-7K2P
KOMU-NALO-CHKA-9X4Q
TEPL-ODIM-LVIV-3R8N
ECOH-OME2-026L-6W5M
```

Натисніть **Відкрити Premium**, вставте ключ і натисніть **Активувати Premium**. Поле автоматично додає дефіси та переводить латинські літери у верхній регістр.

Валідатор перевіряє формат `XXXX-XXXX-XXXX-XXXX` і входження до чіткого списку. Активація зберігається в localStorage та перевіряється при завантаженні. Це демонстраційна система без платежів і сервера: код і ключі відкриті, тому вона не захищає комерційну ліцензію. Для платного продукту потрібні серверна перевірка й облік ліцензій.

## Дані та стійкість

- «КомуналОчка» автоматично не надсилає показники, адреси чи реквізити постачальникам: запитуються лише їхні публічні сторінки. Користувач сам переносить підготовлені дані в офіційну форму й відправляє їх там. Немає аналітики чи зовнішнього ШІ. Google Fonts отримує стандартний запит браузера для шрифту.
- localStorage не шифрується; користувачі цього браузера можуть прочитати дані. JSON-копія тепер містить також особові рахунки, телефон, літери прізвища та журнал передачі, якщо їх внесено. Зберігайте копію у себе.
- Помилка доступу/квоти відображається явно. Застосунок продовжує обчислення в пам’яті, але не заявляє, що зміни збережені. Пошкоджений попередній запис не перезаписується автоматично.
- Дані імпорту перевіряються: версія, місяці, типи полів, унікальні помешкання та місяці, ліміти, завершені розрахунки. Максимум — 5 МБ на файл, 5 помешкань, місяці 2020–2100.
- Користувацький текст екранується перед додаванням у HTML. Імпорт не виконує HTML або JavaScript.
- Інші вкладки отримують зміни через подію `storage`. Одночасне редагування не має серверного вирішення конфліктів: останнє збереження є поточним.
- Підтримуються підписи полів, клавіатурний фокус, нативні діалоги, live-повідомлення, режим зменшення анімації та мобільна навігація.

## Перевірка та статична збірка

Потрібен Node.js 20+. Для 17 тестів ядра та збірки npm-пакети не потрібні:

```sh
node --check app.js
node --test tests/core.test.cjs
node scripts/build.mjs
```

Еквівалентно: `npm test`, `npm run build`. Для необов’язкової перевірки у справжньому браузері:

```sh
npm install --no-save playwright@1.62.1
npx playwright install chromium
npm run test:browser
npm run test:transfer
```

Браузерні тести використовують контрольовані відповіді постачальників; перевіряють також CORS-помилку, відсутність тихої заміни тарифу, Premium, профілі, JSON, друк, збереження та ширини 390/768/1440 px. За замовчуванням відкривають локальний файл. За потреби:

```sh
TEST_URL=http://127.0.0.1:4173 BROWSER_CHANNEL=chrome npm run test:browser
npm run test:transfer
```

Знімки зберігаються в `test-results/` і не потрапляють до Git. Браузерні тести потребують дозволу середовища на запуск Chrome. Стан фактично виконаних перевірок наведено в `VERIFICATION.md`.

```sh
brew install gh
gh auth login
```

Для нового розпакованого каталогу без Git-історії:

```sh
cd komunalochka-lviv
git init -b main
git add .
git commit -m "Initial commit: Lviv utility calculator"
gh repo create komunalochka-lviv --public --source=. --remote=origin --push
```

Якщо Git ще не має вашого автора, перед комітом задайте **свої** значення локально для цього репозиторію:

```sh
git config user.name "Ваше ім’я"
git config user.email "Ваш email або GitHub noreply email"
```

Підготовлений робочий каталог може вже містити `.git` та початковий коміт. Тоді достатньо:

```sh
cd komunalochka-lviv
gh auth login
gh repo create komunalochka-lviv --public --source=. --remote=origin --push
```

Якщо репозиторій з таким ім’ям уже існує, не перезаписуйте його: перевірте `gh repo view komunalochka-lviv` і оберіть іншу назву або свідомо під’єднайте наявний remote. Файли `.env`, `node_modules/`, `.DS_Store`, збірка та результати тестів виключені через `.gitignore`.

### Сам сайт на GitHub Pages

Після push у GitHub відкрийте **Settings → Pages → Deploy from a branch → main → / (root) → Save**. Кореневі файли вже готові до статичного розміщення. У налаштуваннях може знадобитися трохи часу для появи URL; відкрийте адресу, яку покаже GitHub. Hash-навігація та відносні шляхи працюють у підкаталозі репозиторію.

Для іншого статичного хостингу можна використати кореневі чотири вебфайли або вміст `dist/` після `node scripts/build.mjs`.
